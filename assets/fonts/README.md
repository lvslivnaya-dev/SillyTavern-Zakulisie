# Шрифты и их авторы

Все шрифты свободные: [SIL Open Font License 1.1](https://openfontlicense.org). Их можно распространять вместе с расширением, если рядом лежит лицензия (папка `licenses`). Файлы взяты из [Fontsource](https://fontsource.org) 5.2.6 (те же файлы, что на Google Fonts) и не изменялись. Каждое начертание разбито на наборы символов: кириллица, расширенная кириллица, латиница, расширенная латиница.

| Семейство в CSS | Шрифт | Начертания | Авторы | Роль |
|---|---|---|---|---|
| PudUI | Nunito | 500, 700 | © 2014 The Nunito Project Authors ([github](https://github.com/googlefonts/nunito)) | настройки и окна |
| PudPost | Lora | 400, 600 | © 2011 The Lora Project Authors ([github](https://github.com/cyrealtype/Lora-Cyrillic)) | текст постов |
| PudSpeech | Comfortaa | 600 | © 2011 The Comfortaa Project Authors ([github](https://github.com/alexeiva/comfortaa)) | прямая речь |
| PudHead | Comfortaa | 700 | то же | заголовки |
| PudThink | Caveat | 500 | © 2014 The Caveat Project Authors ([github](https://github.com/googlefonts/caveat)) | мысли |
| PudName | Lobster | 400 | © 2010 The Lobster Project Authors ([github](https://github.com/impallari/The-Lobster-Font)) | имена в чате |
| PudSkip | Marck Script | 400 | © 2011 Denis Masharov, Marck Fogel | таймскипы |

Почему так:
- пост — книжная антиква (Lora);
- прямая речь — круглый плотный гротеск (Comfortaa);
- мысли — рукописный (Caveat).

Три разных характера, поэтому речь и мысли не спутать ни друг с другом, ни с повествованием.

Размеры в `style.css` подогнаны по высоте строчной «о»: Lora 0.532, Comfortaa 0.555, Caveat 0.367, Marck Script 0.372.
